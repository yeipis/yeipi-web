Sitio web personal de **Yeipi**, enfocado en alto rendimiento, accesibilidad y diseño minimalista moderno.

### Características técnicas:
- **Framework:** Astro con arquitectura de islas y contenido estático compilado.
- **Estilos:** Tailwind CSS v4 con paleta cuidada y tipografía optimizada.
- **CI/CD:** Flujo automatizado de despliegue a GitHub Pages con validación estricta de dependencias.
- **Contenido:** Gestión tipada con esquemas Zod en Astro Content Collections.
